# CONTROL Fandom

A fandom page about the video game CONTROL, built as a web
development exercise with HTML, CSS and vanilla JavaScript.

## Description

The page presents the game CONTROL with a fan-focused layout that
includes images, sections with information about the game and basic
interactivity through JavaScript.

## Features

- Static page with a fandom-style design
- Images organized in an `img/` folder
- Custom styles in `css/style.css`
- Basic interactions in `js/script.js`

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript

## Structure

- `index.html` - main page
- `css/style.css` - page styles
- `js/script.js` - page interactions
- `img/` - images used by the page
